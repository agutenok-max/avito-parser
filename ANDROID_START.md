# 🤖 Запуск бота на Android-телефоне дома

Зачем: Avito не пускает серверы хостингов (проверено командой `/diagnose` на Amvera:
«Доступ ограничен: проблема с IP»). С обычного домашнего интернета страницы Avito открываются,
поэтому бот можно держать на Android-телефоне, который постоянно лежит дома на зарядке и подключён к Wi‑Fi.

Компьютер не нужен. Время: ~30 минут. Расходы: только сам телефон.

---

## Какой телефон подойдёт

- **Android 8 или новее**, оперативная память **от 2–3 ГБ**. Подойдёт недорогой б/у телефон.
- Новый не обязателен: бот лёгкий (около 50–100 МБ памяти), браузер ему на телефоне не нужен.
- Удобнее всего Samsung, Google Pixel, Motorola, Nokia. Xiaomi, Redmi, POCO, Huawei и Honor тоже работают,
  но у них агрессивная экономия батареи: обязательно выполните шаг 3 полностью.
- Телефон будет всё время **на зарядке и в домашнем Wi‑Fi**. SIM-карта не нужна.

---

## Шаг 0. Остановите бота на Amvera

Один и тот же бот не может работать в двух местах одновременно. Telegram отдаёт сообщения только одному.

Amvera → проект → кнопка **паузы ⏸**. Деньги перестанут списываться.
Удалить проект можно позже, когда бот заработает на телефоне.

---

## Шаг 1. Подготовьте телефон

1. Включите телефон, подключитесь к **домашнему Wi‑Fi**, поставьте на зарядку.
2. Установите **Telegram** из Google Play и войдите в свой аккаунт. Он нужен, чтобы скопировать токен бота.

---

## Шаг 2. Установите Termux (через F-Droid)

Termux — это приложение, в котором будет работать бот.

> ⚠️ Termux из Google Play **устарел и не работает**. Ставьте его из F-Droid.

1. Откройте **Chrome** → адрес **f-droid.org** → кнопка **«Скачать F-Droid»**.
2. Откройте скачанный файл. Телефон спросит про установку из неизвестных источников:
   **«Настройки» → разрешить** → вернитесь назад → **«Установить»**.
3. Откройте **F-Droid** и подождите 1–2 минуты, пока обновится список приложений.
4. Через поиск найдите и установите **Termux**.
5. Так же найдите и установите **Termux:Boot** (автозапуск после перезагрузки телефона).
6. **Один раз откройте Termux:Boot** и сразу закройте. Без этого автозапуск не включится.

---

## Шаг 3. Запретите телефону выключать Termux

Иначе Android через некоторое время «усыпит» бота.

1. **Настройки → Приложения → Termux → Батарея** → выберите **«Без ограничений»**
   (или «Не оптимизировать»).
2. То же самое для **Termux:Boot**.
3. На Xiaomi, Redmi и POCO дополнительно: **Настройки → Приложения → Termux → Автозапуск** — включить.
   На Huawei и Honor: **Настройки → Батарея → Запуск приложений → Termux** — «Управлять вручную»,
   включить все три переключателя.

---

## Шаг 4. Скопируйте токен бота и ваш ID

1. **Токен.** В Telegram на этом телефоне откройте **@BotFather** → отправьте `/mybots` →
   выберите своего бота → **«API Token»** → нажмите на токен, он скопируется.
2. **Ваш ID.** Это число, которое вы вписывали в Amvera в переменную `TELEGRAM_ADMIN_ID`
   (Amvera → проект → «Переменные»). Запишите его.

---

## Шаг 5. Установите бота одной командой

1. Откройте **эту инструкцию** в Chrome на Android-телефоне:
   **github.com/agutenok-max/avito-parser** → файл `ANDROID_START.md`.
2. Скопируйте команду ниже (долгое нажатие → «Копировать»):

```
curl -fsSL https://raw.githubusercontent.com/agutenok-max/avito-parser/claude/avito-telegram-bot-om1luy/scripts/android/install.sh | bash
```

3. Откройте **Termux** → долгое нажатие на чёрный экран → **Paste** (Вставить) → кнопка **Enter**
   на клавиатуре.
4. Ждите 5–10 минут. Если появится вопрос с `[Y/n]`, введите `y` и нажмите Enter.
5. Когда скрипт попросит **токен**: долгое нажатие → **Paste** → Enter.
   (Токен из шага 4 ещё в буфере обмена. Если нет — скопируйте его заново в Telegram.)
6. Когда попросит **Telegram ID**: введите число → Enter.
7. В конце появится **«Готово. Бот запущен»** и строки журнала, среди них
   `✅ Бот @… подключён к Telegram`.

Токен сохраняется только на этом телефоне, в папке Termux. В GitHub и в чат он не попадает.

---

## Шаг 6. Проверьте в Telegram

1. Откройте бота → `/start` → появится меню.
2. Отправьте **`/diagnose`**. Должно быть:
   - «Местоположение: … RU», провайдер — ваш домашний интернет;
   - у ссылки поиска **«Список объявлений на странице: есть ✅»**.
3. **Добавьте поиски заново**: «➕ Добавить поиск» → ссылка из приложения Avito.
   Поиски с Amvera на телефон не переносятся. Там всё равно не было ни одного объявления из-за блокировки.
4. Через минуту бот ответит: **«✅ Поиск … подключён. Сейчас на странице N объявлений»**. Всё работает.

---

## Как жить с ботом дальше

- **Ничего делать не нужно.** Телефон лежит на зарядке в Wi‑Fi, в шторке висит уведомление Termux —
  его **не закрывайте** (не нажимайте «Exit»).
- **После перезагрузки** телефона бот запустится сам (Termux:Boot) примерно через минуту.
- **Если бот упадёт**, он сам перезапустится через минуту.

Команды в Termux (набрать и нажать Enter):

| Команда | Что делает |
|---|---|
| `avito status` | работает ли бот |
| `avito log` | последние строки журнала |
| `avito restart` | перезапустить |
| `avito update` | скачать новую версию бота и перезапустить |
| `avito stop` / `avito start` | остановить / запустить |

Когда ассистент сообщит об обновлении бота — откройте Termux и выполните `avito update`.

---

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Бот не отвечает | Termux → `avito status`. Если «не запущен» — `avito start`, затем `avito log` |
| В журнале `Telegram отклонил токен (401)` | Токен скопирован неверно. Termux → `rm ~/avito-bot/.env` → снова выполните команду из шага 5 |
| В журнале `Conflict: terminated by other getUpdates` | Бот ещё работает на Amvera — поставьте его там на паузу (шаг 0) |
| Бот перестаёт отвечать через несколько часов | Повторите шаг 3 (батарея «Без ограничений», автозапуск) |
| `/diagnose`: «Доступ ограничен» и с телефона | Avito временно ограничил частоту. Бот сам сделает паузу; увеличьте интервал: `/interval 10` |
| Нужно сменить токен или ID | Termux → `rm ~/avito-bot/.env` → снова команда из шага 5 |
