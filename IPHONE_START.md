# 📱 Запуск бота с iPhone — пошагово

Нужны только iPhone, Safari и Telegram. Компьютер и терминал не нужны.
Время: ~30 минут. Стоимость: от 290 ₽/мес (хостинг Amvera, оплачиваете сами — см. шаг 2).

Порядок важен: **сначала настраиваем Amvera, и только в самом конце нажимаем «Merge» на GitHub** —
именно это действие отправит код на сервер и запустит бота.

---

## Шаг 1. Создайте бота в Telegram (3 минуты)

1. Откройте **Telegram** → вкладка поиска → введите **BotFather** → откройте бота с синей галочкой.
2. Нажмите **«Запустить»** (или **Start**).
3. Отправьте сообщение: `/newbot`
4. На вопрос об имени отправьте любое название, например: `Мой Avito монитор`
5. На вопрос о username отправьте уникальное имя латиницей, обязательно с окончанием `bot`,
   например: `avito_monitor_ivan_bot`. (Если занято — придумайте другое.)
6. BotFather пришлёт сообщение с **токеном** — длинная строка вида `1234567890:AAH...`.
   **Нажмите на токен** — он скопируется. Откройте **Заметки** → новая заметка → вставьте.

> 🔒 Токен — это пароль. Не отправляйте его никому (в том числе в чат с ассистентом),
> не вставляйте на GitHub. Он нужен только в Amvera на шаге 4.

---

## Шаг 2. Зарегистрируйтесь в Amvera и пополните баланс

1. Откройте **Safari** → адрес **cloud.amvera.ru** → зарегистрируйтесь.
2. Пополните баланс (раздел баланса/оплаты в личном кабинете).
   Тарифы Amvera (за 30 дней, списание поминутно, по данным docs.amvera.ru):

   | Тариф | Память | Цена | Подходит? |
   |---|---|---|---|
   | Пробный | 100 МБ | 170 ₽ | ❌ мало памяти |
   | **Начальный** | 500 МБ | **290 ₽** | ✅ рекомендую для начала |
   | Начальный Плюс | 1 ГБ | 490 ₽ | ✅ с запасом |

   Бот в работе занимает около 50–100 МБ памяти, поэтому «Начальный» достаточно.

---

## Шаг 3. Создайте проект в Amvera

1. В личном кабинете нажмите **«Создать проект»**.
2. Тип: **«Приложение»**.
3. Название: `avito-bot`. Тариф: **«Начальный»**. Нажмите **«Далее»**.
4. Шаг **«Загрузка данных»**: ничего не загружайте, нажмите **«Далее»**
   (код придёт из GitHub автоматически на шаге 7).
5. Шаг **«Переменные»** — нажмите **«Добавить переменную или секрет»** и добавьте **секрет**:
   - Название: `TELEGRAM_BOT_TOKEN`
   - Значение: вставьте токен из Заметок (долгое нажатие → «Вставить»).
6. Шаг **«Конфигурация»**: если Amvera спросит окружение — выберите **Docker**.
   Если попросит параметры: Dockerfile — `Dockerfile`, порт контейнера — `8080`,
   постоянное хранилище — `/data`. (Эти же настройки записаны в файле `amvera.yml` в репозитории —
   Amvera возьмёт их оттуда.)
7. Нажмите **«Завершить»**. Ошибка первой сборки сейчас — это нормально: кода ещё нет.

---

## Шаг 4. Токен GitHub для Amvera

Amvera нужен токен, чтобы забирать код из вашего репозитория.

1. Откройте новую вкладку Safari → **github.com** → войдите.
   Если не видно нужных пунктов меню, нажмите **«аА»** в адресной строке →
   **«Запросить настольный веб-сайт»**.
2. Нажмите на **аватар** (справа вверху) → **Settings**.
3. В самом низу меню слева: **Developer settings** → **Personal access tokens** → **Fine-grained tokens**.
4. **Generate new token**.
5. Token name: `amvera`. Expiration: **No expiration** (или 1 год).
6. Repository access: **Only select repositories** → выберите **avito-parser**.
7. Permissions → **Repository permissions**:
   - **Contents** → **Read-only**
   - **Webhooks** → **Read and write**
8. Внизу **Generate token** → **скопируйте** токен (`github_pat_...`) → вставьте в Заметки.
   Повторно GitHub его не покажет. Этот токен даёт доступ только к одному репозиторию.

Если Amvera не примет такой токен: **Tokens (classic)** → **Generate new token (classic)** →
Expiration: No expiration → галочки **public_repo** и **admin:repo_hook** → **Generate token**.

---

## Шаг 5. Подключите GitHub в Amvera

1. Вернитесь во вкладку Amvera → откройте проект `avito-bot` → вкладка **«Репозиторий»**.
2. Выберите **GitHub**.
3. Вставьте **токен GitHub** из шага 4 (если есть поле для токена).
4. Событие: **Push**.
5. **Секрет вебхука**: придумайте любое слово, например `avitobot2026`, запишите в Заметки.
6. Ветка: `main`.
7. **Скопируйте адрес**, который покажет Amvera (ссылка для вебхука) → вставьте в Заметки.
8. Нажмите **«Применить»**.

---

## Шаг 6. Добавьте вебхук на GitHub

1. Safari → откройте **github.com/agutenok-max/avito-parser**.
2. Вкладка **Settings** (у репозитория) → слева **Webhooks** → **Add webhook**.
3. **Payload URL**: вставьте адрес из Amvera (шаг 5.7).
4. **Content type**: `application/json`.
5. **Secret**: то же слово, что в шаге 5.5.
6. «Which events…»: **Just the push event**.
7. Нажмите **Add webhook**.

---

## Шаг 7. Отправьте код на сервер (Merge)

1. На странице репозитория откройте вкладку **Pull requests** → откройте Pull Request
   «Telegram-бот мониторинга новых объявлений Avito 24/7».
2. Внизу нажмите **Merge pull request** → **Confirm merge**.
3. GitHub сообщит Amvera об изменениях, и начнётся сборка (5–10 минут).

> Если случайно нажали Merge раньше, чем настроили вебхук (шаги 5–6), — ничего страшного:
> напишите ассистенту «перезапусти сборку», он отправит небольшое изменение в `main`, и сборка начнётся.

---

## Шаг 8. Проверьте, что приложение запустилось

1. Amvera → проект → вкладка **«Лог сборки»**: в конце должно быть сообщение об успешной сборке.
2. Статус проекта должен стать **«Приложение запущено»**.
3. Вкладка **«Лог приложения»** (нажмите «Загрузить историю», если пусто). Ищите строки:
   - `✅ Бот @ваш_бот подключён к Telegram`
   - `Постоянное хранилище подключено: /data`
   - `Мониторинг запущен`

Если видите `Telegram отклонил токен (401)` — токен вставлен неправильно: исправьте секрет
`TELEGRAM_BOT_TOKEN` во вкладке «Переменные» и перезапустите проект.

---

## Шаг 9. Привяжите бота к себе

1. Telegram → найдите своего бота по username из шага 1 → **Запустить**.
2. Бот ответит: «Ваш Telegram ID: `123456789`». **Нажмите на число** — оно скопируется.
3. Amvera → **«Переменные»** → **«Добавить переменную или секрет»**:
   - Название: `TELEGRAM_ADMIN_ID`
   - Значение: ваш ID.
4. Перезапустите проект (кнопка перезапуска или **«Выключить»** → **«Включить»**).
5. Через минуту отправьте боту `/start` — появится **главное меню с кнопками**. 🎉

Теперь ботом можете управлять только вы.

---

## Шаг 10. Проверьте, что бот работает

1. Нажмите **«📊 Статистика»**. Должно быть:
   - «Мониторинг: 🟢 работает»
   - «💾 База данных: в постоянном хранилище ✅»
2. Откройте приложение **Avito**, найдите нужные товары, настройте фильтры (город, цена…).
3. Нажмите **«Поделиться»** → **«Скопировать»**.
4. В боте нажмите **«➕ Добавить поиск»** → вставьте ссылку → отправьте.
5. В течение минуты бот напишет: **«✅ Поиск … подключён. Сейчас на странице N объявлений…»**.
   Это значит, что Avito открылся и всё работает. Дальше будут приходить только новые объявления.

Если вместо этого пришло **«⛔ Avito временно ограничил доступ»** — бот сам подождёт и повторит.
Если такое сообщение приходит часами — см. раздел «Если Avito блокирует» в `DEPLOY.md`.

---

## Обновления в будущем

Любые изменения, попавшие в ветку `main` на GitHub, Amvera соберёт и запустит автоматически.
Ваши поиски и история хранятся в `/data` и при обновлении не теряются.
