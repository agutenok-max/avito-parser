# Запуск бота 24/7 — пошагово, только с iPhone

Компьютер не нужен. Всё делается в Safari и Telegram. Займёт около 20–30 минут.

---

## ⚠️ Сначала важное: где должен работать бот

Avito **блокирует запросы с зарубежных серверов и многих серверов дата-центров**.
Это проверено при подготовке проекта: с сервера в США Avito отвечает страницей
«Доступ ограничен: проблема с IP» и обычному запросу, и настоящему браузеру Chromium.

Поэтому:

- **Рекомендуется российский хостинг — Amvera Cloud** (amvera.ru). Сервер в России, есть постоянное
  хранилище для базы данных, сборка из Dockerfile, подключение GitHub, управление через сайт с телефона.
  Файл настроек `amvera.yml` уже лежит в репозитории.
- Railway / Render / Fly.io технически подходят (файл `railway.toml` тоже есть), но их серверы за границей,
  и Avito, скорее всего, будет их блокировать. Кроме того, у них нет бесплатного тарифа для постоянной работы.
- **Полностью бесплатного варианта, который работает 24/7 с Playwright и постоянной базой, нет.**
  Amvera платная (сотни рублей в месяц), точные цены смотрите на amvera.ru при регистрации —
  я не подключал никаких платных услуг.

Даже с российского сервера Avito может иногда ограничивать доступ. Бот это видит, делает паузу
и пишет вам — обходить защиту Avito он не пытается.

## Шаг 0. Код уже в GitHub

Все изменения лежат в ветке `claude/avito-telegram-bot-om1luy` репозитория
`agutenok-max/avito-parser`. Хостинг можно подключить прямо к этой ветке, либо сначала
слить её в `main` (Pull Request на github.com → «Merge pull request»).

## Шаг 1. Создайте бота и получите токен (Telegram, 3 минуты)

1. Откройте Telegram, в поиске наберите **@BotFather** (с синей галочкой) и откройте его.
2. Нажмите **«Запустить» / Start**.
3. Отправьте команду `/newbot`.
4. Напишите название бота, например: `Мой Avito монитор`.
5. Напишите имя пользователя бота — латиницей и обязательно с окончанием `bot`,
   например: `my_avito_monitor_123_bot`.
6. BotFather пришлёт сообщение с токеном вида `1234567890:AAH...`.
   **Нажмите на токен — он скопируется.** Сохраните его в «Заметках» (никому не показывайте).

> 🔒 Токен — это пароль от бота. Никогда не вставляйте его в файлы на GitHub.
> Он вводится только в разделе «Переменные/Секреты» хостинга.

---

## Шаг 2. Регистрация в Amvera (Safari)

1. Откройте в Safari **amvera.ru** → «Войти / Регистрация».
2. Зарегистрируйтесь (почта или Telegram/Яндекс/GitHub, как предложит сайт).
3. Посмотрите тарифы и пополните баланс на сумму минимального месяца
   (это ваше решение — без пополнения сервис не запустится).
   - С браузером Chromium (режим по умолчанию) берите тариф **не меньше 1 ГБ памяти**.
   - Можно взять тариф дешевле, если в шаге 4 добавить переменную `FETCH_MODE` = `http`
     (бот будет работать без браузера — обычными запросами, памяти нужно ~150 МБ).

---

## Шаг 3. Создайте проект и подключите GitHub

1. В Amvera нажмите **«Создать» → «Приложение»** (проект).
2. Название: `avito-bot`. Выберите тариф.
3. Способ загрузки кода: **«Подключить репозиторий GitHub»**.
4. Если Amvera попросит токен GitHub:
   1. Откройте новую вкладку Safari → **github.com** → войдите.
   2. Нажмите на свой аватар → **Settings** → внизу **Developer settings** →
      **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
   3. Token name: `amvera`, Expiration: на ваш выбор (например, 1 год).
   4. Repository access → **Only select repositories** → выберите `avito-parser`.
   5. Permissions → Repository permissions → **Contents: Read-only** (и **Webhooks: Read and write**,
      если Amvera просит автодеплой).
   6. **Generate token** → скопируйте → вставьте в Amvera.
5. Выберите репозиторий `avito-parser` и ветку (`main`, если вы слили изменения, или
   `claude/avito-telegram-bot-om1luy`).
6. Amvera сама найдёт файл `amvera.yml` (Docker, порт 8080, постоянное хранилище `/data`).
   Если спросит параметры — укажите: окружение **Docker**, порт контейнера **8080**,
   постоянное хранилище **/data**.

---

## Шаг 4. Добавьте секреты (переменные)

В проекте откройте раздел **«Переменные»** и добавьте:

| Имя | Значение | Тип |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 | **Секрет** |
| `FETCH_MODE` | `http` — только если выбрали тариф < 1 ГБ (иначе не добавляйте) | обычная |

`TELEGRAM_ADMIN_ID` добавим в шаге 6 — сначала узнаем ваш ID.

---

## Шаг 5. Запуск

1. Нажмите **«Собрать» / «Пересобрать»** (первая сборка ~5–10 минут — скачивается браузер).
2. Когда статус станет «Запущено», откройте раздел **«Логи»** — там должна быть строка
   `✅ Бот @ваш_бот подключён к Telegram`.

---

## Шаг 6. Узнайте свой Telegram ID и закройте бота от посторонних

1. В Telegram найдите своего бота по имени из шага 1 и нажмите **Start**.
2. Бот ответит: «Ваш Telegram ID: `123456789`». Нажмите на число — оно скопируется.
3. В Amvera → «Переменные» добавьте `TELEGRAM_ADMIN_ID` = это число.
4. Нажмите **«Перезапустить»**.
5. Снова отправьте боту `/start` — появится главное меню с кнопками. Готово!

Теперь бот слушается только вас. Посторонние получат ответ «Это личный бот».

---

## Шаг 7. Добавьте первый поиск

1. Откройте приложение Avito, найдите нужный товар, настройте фильтры (город, цена…).
2. Нажмите **«Поделиться»** → **«Скопировать»** (или скопируйте адрес страницы в Safari).
3. В боте нажмите **«➕ Добавить поиск»** и вставьте ссылку.
4. Через минуту бот напишет «✅ Поиск подключён…» — он запомнил текущие объявления.
   Дальше будут приходить только новые.

Если вместо этого пришло «⛔ Avito временно ограничил доступ» — см. раздел ниже.

## Управление

- **Статистика:** кнопка «📊 Статистика» или `/status` — сколько поисков, найдено, отправлено,
  когда была последняя и будет следующая проверка, последние ошибки.
- **Интервал:** «⚙️ Настройки» → «Интервал проверки» или `/interval 5`. По умолчанию 3 минуты.
  Чем реже проверки, тем меньше шанс ограничений со стороны Avito.
- **Пауза:** кнопка «⏸ Пауза» / `/pause`, продолжить — «▶️ Продолжить» / `/resume`.
- **Отдельный поиск:** `/list` → у каждого поиска кнопки «Пауза», «Проверить», «Удалить».

## Как обновлять

Любые изменения в подключённой ветке GitHub → в Amvera нажмите «Пересобрать»
(или сборка запустится сама, если включён автодеплой). База данных хранится в `/data`
и при обновлении **не теряется**.

## Проверка, что сервис жив

- В Telegram: `/status` — «Мониторинг: 🟢 работает» и время последней проверки.
- В Amvera: раздел «Логи»; адрес `https://<ваш-домен-amvera>/health` (если Amvera выдала домен)
  показывает `"status": "ok"`.
- При падении процесса Docker/Amvera перезапускают контейнер автоматически.

---

## Если Avito блокирует («⛔ Avito временно ограничил доступ»)

Бот сам делает паузу (15 → 30 → 60 → 120 минут) и сообщает, когда доступ восстановится.
Что можно сделать:

1. Увеличить интервал до 10–15 минут (`/interval 15`).
2. Уменьшить число поисков.
3. Если блокировка не проходит часами, значит IP сервера заблокирован Avito.
   Варианты: другой российский хостинг/VPS или свой HTTP-прокси в России
   (переменная `PROXY_URL` = `http://логин:пароль@адрес:порт`). Используйте только
   прокси, которыми вы законно владеете или пользуетесь по договору.

Бот не решает капчи и не обходит защиту Avito — это сделано специально.

## Альтернатива: Railway (серверы за рубежом)

1. railway.com → войти через GitHub → **New Project** → **Deploy from GitHub repo** → `avito-parser`.
2. Settings сервиса → ветка; файл `railway.toml` подхватится автоматически.
3. **Variables:** `TELEGRAM_BOT_TOKEN`, позже `TELEGRAM_ADMIN_ID`.
4. Правой кнопкой (долгое нажатие) по сервису → **Attach Volume** → Mount path: `/data`.
5. Стоимость: тариф Hobby ~5 $/мес + расход памяти. **Высокий риск, что Avito заблокирует IP.**

## Альтернатива: свой VPS с Docker (нужен терминал)

```bash
git clone https://github.com/agutenok-max/avito-parser.git && cd avito-parser
cp .env.example .env && nano .env      # TELEGRAM_BOT_TOKEN, TELEGRAM_ADMIN_ID
docker compose up -d --build
docker compose logs -f
curl http://127.0.0.1:8080/health
# обновление: git pull && docker compose up -d --build
```

База и логи хранятся в папке `./data`, контейнер перезапускается автоматически (`restart: unless-stopped`).
