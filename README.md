# Avito Monitor Bot

Личный Telegram-бот, который круглосуточно следит за новыми объявлениями Avito.
Вы присылаете боту ссылку на поиск Avito, а он сам проверяет её каждые несколько минут
и присылает **только новые** объявления.

> 📱 **Пошаговая инструкция по запуску с iPhone — в [DEPLOY.md](DEPLOY.md).**

## Возможности

- Несколько поисков одновременно (до 20, настраивается).
- Только новые объявления: уже присланные никогда не повторяются, в том числе после перезапуска сервера.
- Бот сам включает сортировку Avito «по дате» (`s=104`), свежие объявления присылаются первыми.
- Красивые уведомления: название, цена, место, дата публикации, описание, фото, кнопка «Открыть объявление».
  Если дата на Avito не указана — бот так и пишет, ничего не выдумывает.
- Метка «🔥 Опубликовано только что» для объявлений не старше часа.
- Интервал проверки по умолчанию 3 минуты, меняется кнопками или командой `/interval`.
- Пауза/продолжение всего мониторинга или отдельных поисков.
- Статистика: активные поиски, найдено объявлений, отправлено уведомлений, последняя и следующая проверка.
- Управлять ботом может только владелец (`TELEGRAM_ADMIN_ID`).
- Если Avito ограничивает доступ (капча, «Доступ ограничен»), бот **не пытается это обойти**:
  делает паузу 15 → 30 → 60 → 120 минут и сообщает об этом.
- База данных SQLite в постоянном хранилище, health check `/health`, автоперезапуск в Docker.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Главное меню (и ваш Telegram ID) |
| `/help` | Инструкция |
| `/add` | Добавить ссылку на поиск (можно `/add <ссылка>` или просто прислать ссылку) |
| `/list` | Мои поиски: пауза, проверка, удаление каждого |
| `/remove` | Удалить поиск |
| `/pause` / `/resume` | Приостановить / возобновить мониторинг |
| `/status` | Состояние и статистика |
| `/interval` | Интервал проверки (кнопки или `/interval 5`) |

Кнопки главного меню: «Добавить поиск», «Мои поиски», «Удалить поиск», «Пауза/Продолжить»,
«Статистика», «Настройки», «Проверить сейчас», «Последние находки».

## Как это устроено

```
telegram_bot/bot.py        — точка входа: Telegram (long polling) + монитор + /health
telegram_bot/handlers.py   — команды и кнопки
telegram_bot/monitor.py    — фоновые проверки, защита от дублей, пауза при блокировках
telegram_bot/formatting.py — тексты уведомлений
services/avito_fetcher.py  — загрузка страницы: HTTP, при неудаче — headless Chromium (Playwright)
services/avito_processor.py— разбор выдачи Avito (HTML-карточки + встроенный JSON с датами)
services/url_tools.py      — проверка ссылок, сортировка по дате
database/monitor_db.py     — SQLite: поиски, объявления, уведомления, настройки
```

Защита от дублей: в таблице `items` уникальный ключ `(search_id, item_id)`. Объявление записывается
в базу **до** отправки; статус меняется на «отправлено» после успешной отправки. При временной ошибке
Telegram отправка повторяется (до 3 попыток), при этом повторно одно и то же объявление не придёт.

При добавлении поиска бот запоминает объявления, которые уже есть на странице, и не присылает их —
приходят только появившиеся после добавления.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | **Обязательно.** Токен от @BotFather |
| `TELEGRAM_ADMIN_ID` | — | **Обязательно.** Ваш Telegram ID (бот покажет его на `/start`) |
| `CHECK_INTERVAL_MINUTES` | `3` | Интервал проверки |
| `MIN_INTERVAL_MINUTES` | `2` | Минимальный интервал |
| `MAX_NOTIFICATIONS_PER_CHECK` | `10` | Не больше N уведомлений на поиск за одну проверку |
| `SEND_PHOTOS` | `true` | Присылать фото |
| `FETCH_MODE` | `auto` | `auto` / `http` / `browser` |
| `BLOCK_PAUSE_MINUTES` | `15` | Пауза при ограничении со стороны Avito |
| `PROXY_URL` | — | Необязательный HTTP-прокси (`http://user:pass@host:port`) |
| `STOP_WORDS` | — | Не присылать объявления с этими словами в заголовке |
| `DATA_DIR` | `data` (`/data` в Docker) | Где хранить базу и логи |

Полный пример — [.env.example](.env.example).

## Локальный запуск и тесты (для разработчика)

```bash
pip install -r requirements-dev.txt
python -m playwright install chromium   # необязательно
python -m pytest -q                     # тесты
cp .env.example .env                    # заполните токен и ID
python -m telegram_bot.bot
```

Docker: `docker compose up -d --build`.
